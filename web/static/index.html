mess

голос, чат и картинки для своих. без полутора гигабайт оперативки.

это сервер. общаться — в приложении:

скачать для Windows, macOS и Linux

вход через Discord, один раз — дальше приложение помнит тебя.

зачем

Discord съедает полтора гига на встроенный Chromium. Тут нативное приложение на Go — около сотни мегабайт в звонке.

как устроено

Группы, в них текстовые и голосовые каналы. Друзей зовёшь ссылкой-приглашением. Медиа идёт напрямую через сервер (SFU), без транскодинга.

чего пока нет

Демонстрации экрана и камеры в приложении — они в планах. Сейчас только голос, чат и картинки.
